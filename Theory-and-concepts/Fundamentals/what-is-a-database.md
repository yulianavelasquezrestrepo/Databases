# ¿Qué es una base de datos?

## Objetivo del tema
Comprender qué es una base de datos, para qué se utiliza y por qué es un componente fundamental en los sistemas de información modernos.

---

## Definición de base de datos

Una **base de datos** es un conjunto organizado de datos relacionados entre sí, que se almacenan de forma estructurada con el objetivo de permitir su **almacenamiento, consulta, actualización y gestión eficiente**.

Los datos en una base de datos representan información del mundo real, como personas, productos, transacciones, eventos o cualquier otro elemento relevante para una organización o sistema.

---

## Características principales de una base de datos

Una base de datos se caracteriza por:

- **Organización estructurada**: los datos siguen un modelo definido (por ejemplo, tablas).
- **Persistencia**: los datos se almacenan de forma permanente.
- **Acceso eficiente**: permite consultar información de manera rápida y controlada.
- **Integridad**: mantiene reglas que garantizan la consistencia de los datos.
- **Seguridad**: controla quién puede acceder o modificar la información.
- **Compartición**: múltiples usuarios o aplicaciones pueden acceder a los datos.

---

## Ejemplo sencillo de base de datos

Supongamos una institución educativa que necesita almacenar información de sus estudiantes.

Una base de datos podría contener información como:

- Identificación del estudiante
- Nombre
- Programa académico
- Correo electrónico
- Fecha de ingreso

Esta información no se guarda de forma desordenada, sino siguiendo una estructura que permita buscar, filtrar y actualizar los datos de manera confiable.

---

## Diferencia entre datos e información

Es importante distinguir entre **dato** e **información**:

- **Dato**: valor individual sin contexto (por ejemplo: `20231045`).
- **Información**: conjunto de datos procesados con significado (por ejemplo: *El estudiante con código 20231045 pertenece al programa de Tecnología en Sistemas*).

Una base de datos permite transformar datos en información útil para la toma de decisiones.

---

## ¿Por qué son importantes las bases de datos?

Las bases de datos son fundamentales porque:

- Soportan la mayoría de los sistemas de información actuales.
- Permiten manejar grandes volúmenes de datos.
- Facilitan la automatización de procesos.
- Garantizan la consistencia y confiabilidad de la información.
- Son la base de aplicaciones web, móviles, empresariales y científicas.

Ejemplos de sistemas que dependen de bases de datos:
- Sistemas académicos
- Sistemas bancarios
- Redes sociales
- Plataformas de comercio electrónico
- Sistemas de salud

---

## Bases de datos en la vida cotidiana

Aunque no siempre sea evidente, las bases de datos están presentes en actividades diarias como:

- Iniciar sesión en una aplicación
- Consultar el saldo bancario
- Realizar una compra en línea
- Usar redes sociales
- Reservar un servicio

Cada una de estas acciones implica el acceso y manipulación de una base de datos.
