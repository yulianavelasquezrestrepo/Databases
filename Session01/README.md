# Introducción a Bases de Datos

## ¿Qué es una base de datos?
Una base de datos es una colección organizada de datos relacionados entre sí, almacenados de forma estructurada, que permiten ser consultados, modificados y administrados de manera eficiente.

A diferencia de archivos sueltos o hojas de cálculo, una base de datos:
- Evita la duplicación innecesaria de información
- Garantiza la integridad y consistencia de los datos
- Permite el acceso concurrente de múltiples usuarios
- Facilita la seguridad y el control de permisos

---

## ¿Por qué son importantes las bases de datos?
Las bases de datos son fundamentales en casi todos los sistemas de información actuales:
- Sistemas académicos
- Aplicaciones web y móviles
- Sistemas bancarios
- Comercio electrónico
- Sistemas de salud

Una mala organización de los datos genera:
- Errores
- Información inconsistente
- Pérdida de tiempo
- Decisiones incorrectas

---

## Base de datos vs hojas de cálculo
Aunque herramientas como Excel permiten almacenar información, **no están diseñadas para manejar grandes volúmenes de datos ni múltiples usuarios simultáneamente**.

| Hojas de cálculo | Bases de datos |
|-----------------|----------------|
| Archivos independientes | Datos centralizados |
| Sin reglas de integridad | Reglas de integridad |
| Difícil escalabilidad | Alta escalabilidad |
| Sin control de concurrencia | Multiusuario |

---

## ¿Qué es un DBMS?
Un **Sistema Gestor de Bases de Datos (DBMS)** es el software encargado de:
- Crear bases de datos
- Almacenar información
- Administrar usuarios y permisos
- Garantizar la integridad y seguridad de los datos
- Ejecutar consultas

### Ejemplos de DBMS
- MySQL
- PostgreSQL
- SQL Server
- Oracle Database

---

## Componentes básicos de un sistema de bases de datos
- **Datos:** información almacenada
- **DBMS:** software gestor
- **Usuarios:** personas o aplicaciones que acceden a los datos
- **Hardware:** servidores y dispositivos
- **Procedimientos:** reglas de uso y administración
